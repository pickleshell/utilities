# Utilities

Small utilities, experiments, and test projects.

## Projects

### [GPU Top](gpu-top)

An htop-style terminal monitor for AMD GPUs, Ollama models, and GPU processes. GPU Top was created as a real development test for [Next Level Agent](https://github.com/pickleshell/next-level-agent).

The [initial task and selected parameters](gpu-top/INITIAL_TASK.md) are included with the source.
